# Glassfin

A polished, Apple-style glass PWA media client for [Jellyfin](https://jellyfin.org). No backend — the browser talks to Jellyfin directly.

## Local development

```bash
npm install
npm run dev      # Vite dev server on http://localhost:5173
```

## Production build

```bash
npm run build
npm run preview  # serves dist/ on http://localhost:4173
```
